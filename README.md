# Robot Hotkey Macro — STORM-XII V3 (16CH + BNO085)

กดคีย์ลัดแล้วโปรแกรมจะพิมพ์โค้ดหุ่นยนต์ลง IDE (Arduino IDE / VS Code) ที่บรรทัดปัจจุบันและขึ้นบรรทัดใหม่ให้เอง
ชุดคำสั่งทั้งหมดมาจากไลบรารี **UnknowRobot_STORMXII_V3_BNO085** (ตรวจชื่อกับไฟล์ `.h` จริงทุกครั้งที่รัน self-test)
ค่า `speed / cm / ms / dir / angle / select / n / L / R` ดึงมาจากหน้าต่างโพยที่ลอยอยู่บนสุดของจอ จึงเปลี่ยนค่าได้ตลอดโดยไม่ต้องแก้โค้ด

> 📄 ผังคีย์ลัดครบทุกปุ่ม + ความหมาย select + ตารางเทียบชุดเดิม → **[MACRO_CHEATSHEET.md](MACRO_CHEATSHEET.md)**

## ⏱ วันแข่ง: อ่าน 1 นาทีจบ

1. ดับเบิลคลิก **`run_macro.bat`** แล้วกด **Yes** ที่หน้าต่าง UAC (สคริปต์จะติดตั้งไลบรารีให้เองตอนรันครั้งแรก)
2. คลิกในหน้าต่าง IDE ตรงบรรทัดว่างใน `Mission()` (ใต้บรรทัด "เขียนโค้ดหลังจากบรรทัดนี้")
3. ตั้งค่าในหน้าต่างโพย เช่น speed 50 / select `'p'` แล้วกดคีย์ลัด เช่น **Ctrl+Alt+1** จะได้ `FFC(50, 'p');` และเคอร์เซอร์ลงไปบรรทัดใหม่ทันที
4. จะคลิกปุ่มในหน้าต่างโพยแทนก็ได้ (ปุ่มที่ไม่มีคีย์ลัดก็กดได้) โปรแกรมจะสลับกลับไปพิมพ์ใน IDE ที่ใช้ล่าสุดให้เอง
5. ปิดโปรแกรมด้วย **Ctrl+Shift+Q**

### สูตรจำคีย์ลัด (ทุกตัวกด Ctrl+Alt)

| กลุ่ม | คีย์ | จำว่า |
|---|---|---|
| ตามเส้นจนเจอแยก | `1..4` = `FFC FFC2 FFL FFR` | เติม **Shift** = ถอยหลัง (`BB…`) |
| ระยะ/เวลา/ขาว | `5` = `FFcm`, `6` = `FFtimer`, `7` = `FFWhite` | เติม **Shift** = ถอยหลัง · select ใส่เมื่อเลือกตัวอักษร (None = ไม่ใส่) |
| หมุนหาเส้น | `Shift+A/D` = `SpinL/SpinR` · `Shift+J/L` = `SpinL2/SpinR2` | J/L = ข้ามไปเส้นที่ 2 |
| เข้ากลาง / หยุด | `Shift+C` = `ToCenter()` · `Shift+S` = `MotorStop()` | |
| กินโค้งตามระยะ | `T`/`Y` = `FFcmCirCleL/R` | เติม **Shift** = ถอยหลัง |
| ตามเส้นจนถึงทิศ | `;`/`'` = `ffdircl/ffdircr` · `Z`/`X` = `ffdirclg/ffdircrg` | เติม **Shift** = ถอยหลัง |
| **รีเซ็ตมุมไจโร** | **`O`** = `resetAngles();` · `Shift+O` = `SetRobotAngle();` · `Shift+N` = `resetAnglesDir(dir);` | O หน้าตาเหมือนเลข 0 · มีปุ่มสีเขียวเข้มบนแถบบนสุดด้วย |
| Gyro วิ่งตรง | `G` = `FFcmG`, `H` = `FFcmGS`, `V` = `FFtimerG`, `B` = `FFBG` | เติม **Shift** = ถอยหลัง |
| Gyro หันทิศ | `N` = `spinDirection`, `M` = `turnDirection`, `Shift+M` = `turnDirectionB` | ใช้ค่า dir |
| Gyro หมุน/เลี้ยวตามองศา | `A`/`D` = `SpinLG/SpinRG`, `Q`/`E` = `TurnLG/TurnRG` · `F` = `spinDegree`, `Shift+F` = `turnDegree` | Shift ที่ Q/E = เลี้ยวถอยหลัง · F ใช้องศามีเครื่องหมาย |
| Servo | `F1..F12` · ท่าผสม `Shift+F1..F8` | ฟังก์ชันอยู่ใน `Servo.ino` ของสเก็ตช์ตัวอย่าง |
| ตั้งทิศ dir | `I` `L` `K` `J` = 0 / 90 / 180 / 270 | วางเป็นลูกศร: I บน, L ขวา, K ล่าง, J ซ้าย |
| ตั้ง select | `P` `C` `S` = 'p' 'c' 's' · `,` = 'l' · `.` = 'r' | `/` วนตัวถัดไป · `U` สลับตัวเล็ก/ใหญ่ |
| ความเร็ว | `=`/`-` = ±5 · `8`/`9`/`0` = SLOW/DEFAULT/FAST (30/50/80) | |
| ระยะ / เวลา | `]`/`[` = cm ±5 · `Shift+]`/`Shift+[` = ms ±100 | |
| อื่น ๆ | `R` = พิมพ์คำสั่งล่าสุดซ้ำ · `Shift+P` = หยุดชั่วคราว · `Shift+W` = ซ่อนหน้าต่าง | |

บนปุ่มในหน้าต่างเขียนคีย์ย่อไว้ท้ายชื่อ เช่น `FFcmCirCleL T` = Ctrl+Alt+T, `BBC S+1` = Ctrl+Alt+Shift+1

### ตัวเลือกในหน้าต่างโพย

- **End ก่อน / Enter หลัง**: กด End ก่อนพิมพ์ และขึ้นบรรทัดใหม่หลังพิมพ์ (IDE จัดย่อหน้าให้)
- **ชื่อย่อ**: ใช้ชื่อย่อที่ไลบรารีมีให้ `sdg tdg tdbg turndir_none turndirb_none` แทน `spinDirection turnDirection …`
- **ใส่ speed (opt.)**: คำสั่งที่ speed เป็น optional (`SpinL SpinR SpinLB … SpinLG TurnRG spinDegree spinDirection …`) ติ๊ก = `SpinL(50);` ไม่ติ๊ก = `SpinL();`
- **Gyro ใส่ act / Gyro ใส่ dir**: ใส่ select / dir ต่อท้าย `FFcmG BBcmG FFcmGS BBcmGS FFtimerG BBtimerG` (dir ใช้กับ `FFBG BBBG` ด้วย) แต่ละตัวอิสระกัน เช่น `FFcmG(50, 30, 90);`
- **ช่อง n / L / R** (คอลัมน์ขวา): `n` ใช้กับ `FFNUM FFSUM Balance* ServoWrite` · `L R` = ความเร็วล้อซ้าย/ขวาของ `Move Motor rotateDegree rotateDir`
- **Action Pad**: ตัวอักษร select 24 ตัว (เพิ่ม `n` ไหลต่อ และ `f` เบรกไจโร สำหรับชุด `ffdircl…/ffdeg…/rotateDir`) + ปุ่ม **None** ใต้แผงจะบอกความหมายทั้งโหมดตามเส้นและโหมด Gyro
- เอาเมาส์ชี้ปุ่มคำสั่งจะเห็นตัวอย่างโค้ดที่จะถูกพิมพ์ก่อนกด
- ไม่มีช่อง tol แล้ว เพราะไลบรารีนี้ไม่มีพารามิเตอร์ tol (ถ้าใส่เลขที่ 4 ไป `ffdircl` จะไปตรง overload ของ kp แบบเงียบ ๆ)

## ปรับแต่ง (`macro.py`)

ค่าที่ตั้งไว้อยู่บนสุดของไฟล์ (ค่าเริ่มต้นอิงจากสเก็ตช์ตัวอย่างของไลบรารี):

```python
DEFAULT_SPEED = 50
FAST_SPEED = 80
SLOW_SPEED = 30
DEFAULT_CM = 30
DEFAULT_MS = 1000
DEFAULT_DIR = 0
DEFAULT_ANGLE = 90
DEFAULT_ACTION = 'p'
DEFAULT_N = 7
DEFAULT_L, DEFAULT_R = 60, 20
```

- **เพิ่มหรือแก้คำสั่ง**: แก้ในตาราง `MACROS` ตัวอย่างเช่น
  - `Cmd(CAT_LINE, 'ctrl+alt+1', 'FFC', 'speed act')` คือ ชื่อฟังก์ชันตามด้วยรายการพารามิเตอร์ (ใส่ `None` แทนคีย์ลัด = มีแค่ปุ่มบนจอ)
    เครื่องหมายท้ายชื่อ: `?` = optional ตามติ๊ก · `act~` = ตัดทิ้งเมื่อเลือก None · `act!` = บังคับมี ถ้า None ใช้ `'p'` · `cmi` = cm แบบจำนวนเต็ม
  - `Cmd(CAT_CUSTOM, 'ctrl+alt+shift+8', 'delay(ms)', raw='delay({ms});')` คือ ข้อความแม่แบบที่ใช้ `{speed} {cm} {ms} {dir} {angle} {act} {n} {L} {R} {fast} {slow}` ได้
  - แท็บและจำนวนคอลัมน์ของปุ่มตั้งใน `TABS`
- **ตรวจหลังแก้**: `run_macro.bat check` หรือ `python macro.py --selftest` จะเช็กว่าคีย์ลัดไม่ซ้ำ ผลลัพธ์ทุกคำสั่งตรงกับตาราง `EXPECTED`
  และ **ทุกชื่อฟังก์ชันมีอยู่จริง** ในโฟลเดอร์ไลบรารี (`LIB_DIR`)
- **ทดสอบคอมไพล์**: `python macro.py --sketch > Mission.ino` แล้วเอาไปทับ `Mission.ino` ในสำเนาของสเก็ตช์ตัวอย่าง กด Verify (ห้ามอัปโหลดไปวิ่ง)
- **อัปเดตโพย**: `python macro.py --table` พิมพ์ตารางคีย์ลัด (ส่วนท้ายของ MACRO_CHEATSHEET.md)
- **พิมพ์ช้า/ตกหล่น** (เครื่องช้า): เพิ่มค่า `FOCUS_DELAY` และ `PASTE_SETTLE`

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| กดคีย์ลัดแล้วไม่มีอะไรเกิดขึ้น และ IDE เปิดแบบ Administrator | เปิดโปรแกรมนี้ผ่าน `run_macro.bat` แล้วกด Yes ที่ UAC (Windows ไม่ยอมให้โปรแกรมสิทธิ์ต่ำกว่าส่งปุ่มเข้าหน้าต่าง admin) |
| สถานะขึ้นว่า "คีย์ลัดที่ใช้ไม่ได้ (โปรแกรมอื่นจองไว้)" | มีโปรแกรมอื่นจองคีย์นั้นไว้ เช่นแผงควบคุมการ์ดจอ Intel/AMD ที่ใช้ Ctrl+Alt+F-key ให้ปิดคีย์ลัดของโปรแกรมนั้น หรือเปลี่ยนคีย์ใน `MACROS` |
| ขึ้นว่า "ยังกด Ctrl/Alt/Shift ค้างอยู่" | ให้ปล่อยปุ่มทั้งหมดก่อน โปรแกรมจะรอให้ปล่อยแล้วค่อยพิมพ์ เพื่อไม่ให้กลายเป็นคีย์ลัดอื่นของ IDE |
| ขึ้นว่า "ยังไม่รู้ว่าจะพิมพ์ลงหน้าต่างไหน" | คลิกที่หน้าต่าง IDE 1 ครั้ง แล้วกดปุ่มหรือคีย์ลัดใหม่ |
| ข้อความใน Clipboard หายหลังพิมพ์ | โปรแกรมคืนค่าเฉพาะข้อความ ถ้าเคย copy รูปไว้ รูปนั้นจะหายไป |

## ปรับปรุงอะไรจากต้นฉบับ

| ต้นฉบับ | ฉบับนี้ |
|---|---|
| `keyboard.add_hotkey` + `keyboard.write` | คีย์ลัดใช้ Win32 `RegisterHotKey` ซึ่งกันไม่ให้คีย์ลัดหลุดไปถึง IDE ไม่ทำให้ปุ่มค้าง และอ้างอิงตำแหน่งปุ่มจึงใช้ได้ทั้งแป้นไทย/อังกฤษ |
| พิมพ์ทีละตัวอักษร ซึ่งเพี้ยนเมื่อแป้นเป็นภาษาไทย และ IDE เติม `)` `'` ซ้ำ | วางผ่าน Clipboard (Ctrl+V ส่งเป็น virtual-key) แล้วคืนค่า Clipboard เดิม |
| ค่าตายตัวในโค้ด | หน้าต่างโพยแบบ Always-on-Top ที่เปลี่ยนค่าได้ทันที มีพรีวิว และกดปุ่มเพื่อพิมพ์ได้ |
| คีย์ลัด Ctrl+Shift+1..6 | ระบบคีย์ลัดแบ่งหมวดตามหลักจำ และตรวจคีย์ซ้ำอัตโนมัติ |
| | กดปุ่มว่าง (VK 0xE8) คั่นทันทีที่คีย์ลัดทำงาน เพื่อไม่ให้ Alt เปิดเมนูของ IDE หรือ Alt+Shift สลับภาษา |

## ไฟล์

- `macro.py`: โปรแกรมหลัก (Python 3.8+ บน Windows ใช้ `tkinter` ที่มากับ Python)
- `MACRO_CHEATSHEET.md`: โพยคีย์ลัดทุกปุ่ม + ความหมาย select + ตารางเทียบชุดเดิม
- `run_macro.bat`: ตัวเปิดโปรแกรม เช็กสิทธิ์ admin หา Python ติดตั้ง `keyboard` + `pyperclip` รัน self-test แล้วเปิดโปรแกรม
  - `run_macro.bat noadmin`: เปิดโดยไม่ขอสิทธิ์ admin
  - `run_macro.bat check`: ติดตั้งและตรวจอย่างเดียว ไม่เปิดโปรแกรม
- `macro.py.bak` / `README.md.bak`: ฉบับก่อนเปลี่ยนเป็นชุดคำสั่ง STORM-XII V3 BNO085
